# Iteration 4.10 — Momentum visual redesign

## Goal
Adopt the "Momentum" design system (violet brand + amber gamification accent, light/dark,
Bricolage Grotesque display font) across the app. Rebuild the six core screens to the
high-fidelity handoff, on real data only. See **ADR-024** and the handoff in
`.ai/design/momentum-handoff/`.

## Guardrails (from ADR-024)
- **Token-first.** Re-point existing CSS-variable tokens + add new ones; the whole app
  reskins before any screen is rebuilt.
- **Real data only.** No XP / levels / Skill IQ on screen — those have no backend. Replace
  those tiles with metrics we have (streak, accuracy, questions answered, category strength).
  True gamification is a later backend iteration (4.2).
- **Taxonomy-aware.** Categories renders Track → Category (ADR-023), not the flat 9-tile grid
  from the mockup.
- **Existing theme provider + router.** Ignore the prototype's localStorage/screen runtime.
- **Fidelity.** Match the handoff's tokens verbatim (hex, clamp() ranges, radii, shadows).

## Delivery — one PR per slice
1. **Design-token + font foundation** — `index.html` fonts, `index.css` token blocks
   (dark + light), `tailwind.config` (display font, amber, gradients, radii, shadow).
   Reskins the whole app. ← *this PR*
2. **Shared chrome** — app-shell header (gradient logo, nav pills, avatar).
3. **Dashboard** — bento grid on real DashboardSummary data.
4. **Categories** — Momentum cards over the Track → Category taxonomy.
5. **Quiz** — question + answer-option states (idle / selected / checked correct+wrong).
6. **Result** — score badge + real reward tiles.
7. **Auth (Login / Register)** — form column + marketing panel.
8. **Landing** — net-new public marketing screen + `/` route. *(last)*

- [x] Owner confirmed the existing-screen slices on the live site (Dashboard/Categories/Quiz/
