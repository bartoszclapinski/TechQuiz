# Iteration 4.2 — Gamification

## Goal
Make the XP / level / Skill IQ signals the Momentum redesign (ADR-024) left slots for **real**,
derived from the attempts we already store — no invented numbers, no schema change. See **ADR-025**.

## Model (ADR-025)
- **XP** — `correctCount × 10` per completed attempt; total = sum. (`correctCount = round(score% × answerCount)`.)
- **Level** — XP to advance L→L+1 is `100 + (L−1)×50`, cumulative → `(Level, XpIntoLevel, XpForNextLevel)`.
- **Skill IQ** — `round(clamp(avgScore,0..100) × 1.6 + min(quizCount×3, 75))`, 0..250; weekly delta =
  now − excluding-last-7-days; tier label replaces the fictional "Top X%" percentile.

## Delivery — one PR per slice
1. **Domain math** — `Gamification` (XP/level/Skill IQ/tier) + `LevelProgress`, TDD in Domain.Tests.
   ← *this PR*
2. **Application/API** — `GamificationCalculator` over `CompletedAttemptRow`; extend
   `DashboardSummaryDto` with a gamification block (all-time, like streak); add `XpEarned` to the
   quiz result. Handler + Application.Tests.
3. **Web** — wire Dashboard (Skill IQ + weekly delta + level/XP bar), Result (XP earned tile),
   Quiz (potential-XP pill). Update `api.ts` types.

## Definition of Done

      shows potential XP.
- [ ] All backend tests green; web build/lint green.
