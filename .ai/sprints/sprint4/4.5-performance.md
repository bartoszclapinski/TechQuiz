# Iteration 4.5 — Frontend performance

## Goal
Cut the initial bundle so the live portfolio (Render free tier, cold starts) paints fast. The whole
app shipped as one ~591 kB chunk (CI warned >500 kB) because every page was eagerly imported.

## What shipped
1. **Route-based code splitting** (#353) — every authed page is `React.lazy` with a `Suspense`
   fallback around the AppShell Outlet (both the chromed path and the focused quiz/review-runner
   path). Landing, Login and the layout wrappers stay eager (entry points).
   - Main chunk **591 → 381 kB (175 → 115 kB gzip)**; each page is its own on-demand chunk
     (dashboard 21 kB, quiz 39 kB, code-challenge 22 kB, result 10 kB…). The >500 kB warning is gone.
2. **Drop unused `recharts`** (#354) — its charts were replaced during the redesign/gamification work;
   already tree-shaken out, removed from `package.json`/lockfile to keep the dep set honest.

## Notes
- Monaco (`@monaco-editor/react`) loads its core at runtime via the package's loader, so it was never
  in the bundle; lazy-loading the code-challenge route still defers the wrapper.
- Vendor-chunk splitting for cross-deploy caching was considered and skipped — marginal for a
  portfolio, and route splitting already removed the warning. Revisit if the core chunk grows.
