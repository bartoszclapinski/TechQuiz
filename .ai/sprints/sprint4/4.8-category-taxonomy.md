# Iteration 4.8 — Category taxonomy (Tracks) + content cleanup

> Phase 4 · Status: in-progress

## Goal
Replace the flat nine-category list with a two-level taxonomy — **Track → Category (quiz) → Question** —
and strip third-party course attribution from all content. Introduces a top-level `Track` domain entity,
splits the three coarse single-quiz banks (SQL, Front-End, Engineering) into focused subcategories,
regroups the six .NET categories under a `.NET` track, nests the Practical Challenges entry under the
categories browse view, and refreshes the live (Neon) data so the new taxonomy shows immediately.

Decision + full taxonomy: **ADR-023**.

## Taxonomy
- **.NET** — C#/.NET · ASP.NET Core · EF Core · ADO.NET · Unit Testing · Design Patterns *(six existing categories, unchanged)*
- **Databases** — Database Fundamentals · Normalization · Querying · Data Manipulation · Schema Definition *(former "SQL" 30 → 5)*
- **Front-End** — JavaScript · TypeScript · HTML · CSS *(former "Front-End" 30 → 4)*
- **Engineering Practices** — Git & Version Control · CI/CD · Clean Code *(former "Engineering Practices" 30 → 3)*
- **Practical Challenges** — frontend nav grouping only (not a DB Track); links to `/challenges`.

## Hard constraints
- **No question wording changes.** Splits repartition the existing per-question factory methods; text,
  options, explanations, and difficulty stay byte-identical. Single-correct `MultipleChoice` invariant holds.
- **No course names** in any category description or question-file doc comment.
- **User data untouched** by the live reset — only quiz-content tables (tracks/categories/quizzes/questions) reset.
