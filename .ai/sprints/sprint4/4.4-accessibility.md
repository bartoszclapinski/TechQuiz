# Iteration 4.4 — Accessibility audit

## Goal
Bring the app (post-Momentum redesign) to a solid WCAG 2.1 AA baseline: visible keyboard focus,
sufficient colour contrast, correct semantics/ARIA, keyboard operability, and reduced-motion respect.
Non-optional per the Phase 4 roadmap.

## Already in place (verified)
- `<html lang="en">`; theme toggle and icon-only buttons carry `aria-label`; inputs have focus styles;
  `react-router` `NavLink` sets `aria-current="page"` on the active link; decorative glows are
  `aria-hidden`; float animations honour `prefers-reduced-motion` (`index.css`).

## Findings → fixes (one PR per slice)
1. **Keyboard focus + skip link** — no global `:focus-visible` ring, so the redesign's custom-styled
   buttons/links/cards (pills, category/quiz cards) have inconsistent/invisible focus. Add a global
   accent focus ring + a "Skip to content" link + a focusable main landmark. ← *this PR*
2. **Colour contrast** — audit the Momentum tokens (muted/secondary text, amber-on-surface,
   white-on-gradient buttons) against AA (4.5:1 body, 3:1 large/UI) and bump any that fail.
3. **Semantics/ARIA sweep** — headings order, landmark regions, remaining icon-only controls,
   progress bars (`role="progressbar"` / `aria-valuenow`), decorative vs meaningful emoji.

## Definition of Done
- [ ] Every interactive element shows a clear keyboard focus indicator; skip link works.
- [ ] Text/UI contrast meets AA in both themes (or documented exceptions).
- [ ] Semantics/ARIA pass a manual audit; keyboard-only can complete the core loop.
- [ ] Web build/lint green; verified on the live site.
- [ ] Owner confirms.
