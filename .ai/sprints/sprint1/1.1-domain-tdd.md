# Iteration 1.1 — Domain layer (TDD)

> Phase 1 · Status: done

## Goal
Domain entities, value objects, and scoring rules exist as pure C# with full unit test coverage. No persistence, no API, no framework dependencies.

## Definition of Done
- [x] `Category`, `Question`, `Option`, `Quiz`, `QuizAttempt`, `Answer` entities defined in `TechQuiz.Domain`
- [x] `Difficulty` enum (Easy/Medium/Hard)
- [x] `QuestionType` enum (MultipleChoice initially; CodeOutput/CodeFix/FillIn placeholders)
- [x] `Score` value object with calculation logic (percentage, correct/total)
- [x] Domain exceptions for invariant violations
- [x] `dotnet test TechQuiz.Domain.Tests` runs 30+ tests, all green (actual: 37)
- [x] Test coverage report shows ≥90% for `TechQuiz.Domain` project (actual: line 98.8% / branch 100%)

## Tasks (in order)

1. **Define entity skeletons** — start with `Category` (Id, Name, Description, IconCode), `Question` (Id, CategoryId, Type, Difficulty, Text, Explanation), `Option` (Id, QuestionId, Text, IsCorrect, OrderIndex)
2. **Write failing tests for Question invariants** — must have at least 2 options, exactly one option marked correct for MultipleChoice, non-empty text
3. **Implement Question invariants** — constructor validation, factory method `Question.Create(...)` that throws on invalid state
4. **Quiz aggregate** — Quiz owns a list of Questions, has a CategoryId, ImmutableQuestionsOrder. Tests for "quiz must have at least 1 question"
5. **QuizAttempt entity** — tracks UserId, QuizId, StartedAt, CompletedAt (nullable), list of Answers
6. **Answer entity** — references QuestionId, SelectedOptionId (nullable for unanswered), submitted timestamp
7. **Score value object** — calculates percentage from `IEnumerable<Answer>` + `IEnumerable<Question>`. Handles: all correct (100%), all wrong (0%), partial, edge case of zero answered
8. **Difficulty breakdown** — method on `Score` that returns `Dictionary<Difficulty, (int correct, int total)>`
9. **Scoring tests** — exhaustive: 0/10, 10/10, 7/10 mixed difficulties, unanswered questions counted as wrong
10. **Domain exceptions** — `DomainException` base, specific types: `InvalidQuestionException`, `QuizAlreadyCompletedException`
11. **Run coverage** — `dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=opencover` and check ≥90% via Coverlet output
