# Iteration 1.7 — Result screen + MVP polish + demo

> Phase 1 · Status: planned

## Goal
Result screen renders score, metrics, and per-question breakdown. MVP is recorded as a demo video. README is updated with MVP screenshots and a "try the demo" link.

## Definition of Done
- [x] Result page matches `mockups/result-*.html`: score hero, 4 metric cards, question breakdown (wrong expanded, correct collapsed), 2 CTAs
- [x] "Show 11 more correct answers" button reveals collapsed correct questions
- [x] "Back to categories" navigates to `/categories`
- [x] "Try again" creates a new attempt for the same quiz, navigates to `/quiz/:newAttemptId`
- [x] Comparison to last attempt shows "+X% from your last attempt" or "first attempt" if none
- [x] Per-question explanation block matches mockup styling (violet border-left, "Explanation" label, body text)
- [ ] All MVP screens have passing Lighthouse accessibility audit (≥90 a11y score)
- [ ] README updated with screenshots, demo credentials, "try the demo" call-to-action
- [ ] 90-second screen recording of full demo flow uploaded (YouTube unlisted or repo asset)

## Tasks (in order)

1. **ResultPage component** — reads `attemptId` from params, `useQuery(['result', attemptId])` fetches result. Renders all sections per mockup
2. **Score hero** — big "87%" with subtle violet gradient background, "Your score" label, optional `+12% from your last attempt` if previous attempts exist
3. **Metric cards** — 4-column grid: Correct/Total, Time, Avg/question, Best score. All values from API response; monospace for time + percentage values
4. **Question breakdown — collapsed correct** — list of correct questions: green check icon, question number monospace, question text muted, chevron-right. Click expands inline to show "Your answer" (which was correct)
5. **Question breakdown — expanded wrong** — red X icon, full question text, "Your answer" (red pill) vs "Correct" (green pill), explanation block with violet border-left
6. **"Show 11 more correct" toggle** — dashed border button below the breakdown. Click reveals all collapsed correct questions
7. **CTAs** — primary violet "Back to categories" with arrow-left icon, secondary outline "Try again" with refresh icon. "Try again" calls `POST /api/quizzes/start` with same categoryId, navigates fresh
8. **Polish pass** — go through every screen, check: keyboard navigation works, focus states visible, color contrast meets WCAG AA, loading states present, error states handled
9. **Lighthouse audit** — run on Login, Categories, Quiz, Result. Fix any a11y issues below 90 score
10. **README update** — add screenshot of each MVP screen (dark + light if space permits), demo credentials block (`demo@techquiz.local` / `Demo123!`), link to demo video
11. **Demo recording** — script: register → demo login → categories → start C# Basics → answer 5 questions (mix correct/wrong) → submit → review result → "Try again". ~90 seconds. Tools: OBS, Cap, or simple browser screen capture. Save to repo or upload to YouTube as unlisted
