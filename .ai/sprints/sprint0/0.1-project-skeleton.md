# Iteration 0.1 — Project skeleton

> Phase 0 · Status: planned

## Goal
A repository that boots, builds, tests, and runs in Docker — with auth scaffolding, CI, commitlint, and an empty "Hello, World" endpoint.

## Definition of Done
- [ ] `dotnet build` succeeds at solution root
- [ ] `dotnet test` runs (even if zero tests yet)
- [ ] `docker compose up` brings the API + Postgres + Seq up healthy
- [ ] `GET /health` returns 200 from inside Docker
- [ ] GitHub Actions CI runs build + test on push to any branch
- [ ] Commitlint blocks non-conventional commit messages
- [ ] First PR merged via squash with a conventional commit title

## Tasks (in order)

1. **Initialize repository** — `git init`, `.gitignore` (Visual Studio + Node + macOS templates merged), `.editorconfig` aligned with `.NET` and frontend conventions
2. **Create solution structure** — `dotnet new sln -n TechQuiz`, create projects: `TechQuiz.Domain` (classlib), `TechQuiz.Application` (classlib), `TechQuiz.Infrastructure` (classlib), `TechQuiz.Api` (web), `TechQuiz.Domain.Tests` (xunit), `TechQuiz.Application.Tests` (xunit), `TechQuiz.Infrastructure.Tests` (xunit). Wire project references following Clean Architecture rules (see ADR-001 in `docs/DECISION_LOG.md`)
3. **Add Identity packages** — `Microsoft.AspNetCore.Identity.EntityFrameworkCore`, configure `IdentityUser`/`IdentityRole` in Infrastructure with PostgreSQL provider (`Npgsql.EntityFrameworkCore.PostgreSQL`). No endpoints yet — just scaffolding
4. **Add JWT auth scaffolding** — `Microsoft.AspNetCore.Authentication.JwtBearer`, configure `AddAuthentication`/`AddJwtBearer` in `Program.cs`, settings in `appsettings.json` with secrets via user-secrets for dev
5. **Configure Serilog** — install `Serilog.AspNetCore`, `Serilog.Sinks.Console`, `Serilog.Sinks.Seq`. Replace default logger in `Program.cs`. Console for dev, Seq for structured viewing
6. **Add health endpoint** — `app.MapHealthChecks("/health")` returning 200 plus DB connectivity check via `AddDbContextCheck`
7. **Create frontend skeleton** — at repo root, `pnpm create vite@latest web --template react-ts`, add Tailwind (`pnpm install -D tailwindcss postcss autoprefixer` + `npx tailwindcss init -p`). Empty React app, no routing yet
8. **Write Dockerfile for API** — multi-stage build: `mcr.microsoft.com/dotnet/sdk:9.0` for build, `mcr.microsoft.com/dotnet/aspnet:9.0` for runtime. Expose port 8080
9. **Write Dockerfile for web** — multi-stage: `node:20-alpine` for build, `nginx:alpine` for runtime serving the Vite `dist/`
10. **Write docker-compose.yml** — services: `api`, `web`, `postgres` (with persistent volume), `seq`. Network setup so api can reach postgres
11. **Add commitlint + husky** — install `@commitlint/cli`, `@commitlint/config-conventional`, `husky`. Configure `.husky/commit-msg` to run commitlint
12. **GitHub Actions CI** — workflow `.github/workflows/ci.yml` running on push to any branch: setup .NET 9, setup Node 20, `dotnet restore && dotnet build && dotnet test`, `pnpm install && pnpm build` for web
13. **README at repo root** — basic "How to run" instructions: clone, `docker compose up`, browse to localhost:8080/health
14. **Open first PR** — branch `feat/project-skeleton` → `master`, PR title `feat: bootstrap solution and docker compose`, merge as squash
